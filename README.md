Created primarily to keep my skills sharp during a break, this is a basic raycast engine that uses the terminal as its viewport.

![1764543433291](https://github.com/user-attachments/assets/dc285624-00c5-4d2c-97a7-b55c9dc386cc)


In short, this means we draw a map out of basic symbols and, based on the player's position, fire a ray at every symbol we can see and look at the distance to determine how 'close' to draw those symbols. By doing so, we represent a 3D space while the 'game' itself is fundamentally 2D.

Basic engine functionality is implemented, as well as enemies and very, very rudimentary combat.
